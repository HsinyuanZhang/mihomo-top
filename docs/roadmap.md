# Roadmap

This roadmap lists possible work beyond the experimental v0.1 feature set. It is directional, not a release promise.

- Improve controller-version compatibility reporting and fixture coverage.
- Improve presentation controls and filtering in the terminal dashboard.
- Add carefully designed, documented support for additional local attribution cases, only where it can remain truthful about uncertainty.
- Provide packaging and reproducible release artifacts after the CLI and schema stabilize.
- Consider opt-in export and integration surfaces while preserving the current local-only controller boundary and no-history default.

Current features—TUI, JSON/JSONL output, loopback-only controller access, optional TCP/tmux attribution, and the schema v1 contract—are documented in the [README](../README.md) and [output schema](output-schema.md), rather than duplicated here.
